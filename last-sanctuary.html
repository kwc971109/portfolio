COMBAT DESIGN · TEAM PROJECT

Last Sanctuary

스태미나와 타이밍으로 행동을 고르게 하는 2D 액션의 전투·행동 기획

FORMAT
Unity · 2D 액션
TEAM
6명 · 기획 2 / 개발 4
PERIOD
2025.06 – 08
ROLE
행동·전투·오브젝트 기획
기획서 모음 ↗ 최종 발표자료 ↗ 개발 영상 ▶
ROLE

맡은 범위

캐릭터 행동과 전투 시스템, 필드 오브젝트, 캐릭터 시스템과 UI, 적 공통 행동, 일반 적 초기 데이터와 필드 오브젝트 데이터 테이블을 기획했습니다. 구현은 팀 개발자 4명이 맡았습니다.

FEEDBACK

“전투가 밋밋하다”는 피드백 이후 바꾼 것

피드백연출 없이 전투 행동만 구현된 상태에서 “전투가 재미없다”, “공격하는 것 같지 않다”는 피드백을 받았습니다.
판단퍼펙트 가드와 궁극기를 전투의 핵심 재미로 정했습니다.
변경두 순간에 시간 정지, 카메라 줌인·흔들림, 색 반전, 효과음을 집중 배치하고, 연출 우선순위와 중복 방지 규칙을 세웠습니다.
결과전투의 긴장감과 보상감이 강화됐다는 피드백을 받았습니다.
COMBAT LOOP

행동마다 비용을 붙인 전투

DEFENSE

방어·회피

스태미나를 쓰는 행동이라 막고 피하는 데도 자원 판단이 필요합니다.

TIMING

퍼펙트 가드

정확한 타이밍에 막으면 적이 그로기에 빠지고 반격 기회가 생깁니다.

RECOVERY

회복

회복 중에 맞으면 회복은 취소되고 아이템만 소모돼, 안전한 시점을 골라야 합니다.
